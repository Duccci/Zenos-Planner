## Summary

Comprehensive refactoring and cleanup of Zeno's MCP server implementation addressing both code architecture and user experience. Refactor three monolithic files (948 + 928 + 478 lines) into focused domain-specific modules using handler factory pattern (40% → <5% duplication), while simultaneously improving end-user experience via simplified setup, VSCode resources, and enhanced error handling. Breaking changes acceptable for improved UX and maintainability.

- Monolithic files: `function-implementations.ts` (948 lines), `src/mcp/tools/*.ts` (928 lines combined), `workflow-logic.ts` (478 lines)

- Single developer per file (merge conflicts, parallel work blocked)
- Difficult to locate specific functions (948-line searches)

**User Experience Issues** (Cleanup):
- Complex MCP setup process with multiple manual steps
- Missing VSCode-standard features (resources)
- Inconsistent error messages

### Task 4: Refactor Tool Handlers to Use Factory

**File(s)**: `src/mcp/tools/*-tools.ts`

**Status**: in_progress — selective application started

**Analysis**: Attempted bulk refactoring using `createSchemaValidatingHandler` factory previously caused test regressions because:
- Factory's generic output extraction doesn't preserve specialized handler logic (array parsing, JSON extraction)
- Tests expect specific `structuredContent` formats that factory doesn't produce for complex tools
- Complex handlers have unique error message formatting and output shaping needs

**Recommendation (refined)**: Apply the factory selectively to simple, schema-validated handlers first, and document exceptions for complex handlers. Steps:
1. Document why certain tools can't use factory (specialized logic)
2. Apply factory selectively to simple handlers (e.g., `proposal-tools.ts`, `config-tools.ts`)
3. Update tests where expected `structuredContent` changes are acceptable or preserve legacy formats via adapter functions
4. Plan incremental refactor work per-tool in follow-up proposals

**Current Status**: 
- [x] Original tool handlers restored and working
- [x] Handler factory available for selective use
- [x] Applied factory to `proposal-tools.ts` (selective refactor) — tests pass
- [x] Applied factory to `config-tools.ts` (selective refactor) — tests pass
- [x] Applied factory to `gate-tools.ts` — tests pass
- [x] Applied factory to `requirement-tools.ts` — tests pass
- [x] Applied factory to `repository-tools.ts` — tests pass
- [x] Applied factory to `analysis-tools.ts` — tests pass
- [x] Updated `workflow-tools.ts` to use shared `parseJsonSafe` from `handler-factory` (reduced duplication) — tests pass
